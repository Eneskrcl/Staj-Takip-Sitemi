# Intern Task Management System (C# Console App)

A simple console-based task management application developed in C#.  
The project simulates an internship/task tracking system with file storage and basic analytics.

---

## Features

- Add, update, and delete tasks (CRUD)
- List tasks with filters:
  - All tasks
  - Pending tasks
  - Completed tasks
  - High priority tasks
  - Overdue tasks
- Search tasks by title or description
- View daily and upcoming tasks
- Basic analytics:
  - Task completion rate
  - Priority distribution
  - Overdue task tracking
- Data persistence using JSON file

---

## Technologies Used

- C#
- .NET Console Application
- Object-Oriented Programming (OOP)
- LINQ
- JSON Serialization (System.Text.Json)

---

## Project Structure

- Program.cs → Main application and UI logic  
- InternTask.cs → Task model  
- TaskManager.cs → Task operations and file handling  
- AnalyticsEngine.cs → Reporting and statistics
